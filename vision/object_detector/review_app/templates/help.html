📖 How to use

← Dashboard

Object Detector Pipeline

0
Open the dashboard & set your API key

Navigate to http://localhost:8000 (or your Cloudflare tunnel URL). On first visit, click API key in the top bar and enter your PIPELINE_API_KEY.

1
Create or select a run

Click + New in the top bar, give the run a name (e.g. kitchen_v1), and press Enter. The run becomes active.

To resume a previous run, select it from the dropdown all stage flags are restored from the filesystem automatically.

2
Upload videos

In Google Drive, create a public shared folder and upload your videos renamed as ClassName<N>.mp4 for example Soap.mp4, Mug.mp4. All files must be flat (no subfolders). The class name is derived from the filename prefix.

Paste the folder URL into the Upload videos card and click ⬇ Pull from Drive. Frames are extracted at 10 fps into images/{ClassName}/. Already-extracted videos are skipped, so re-running is safe.

Tip: Is recommended to use ~20 seconds of video per class.
OPT
Import classes from the Global Repository optional

If any classes were already curated in a previous run, you can reuse them without re-segmenting. Open the REP Object Repository panel (click ▼ Show), pick a label and an identifier from the dropdowns, click + Add for each class, then click ⬇ Import selected into run.

Tip: The repo panel shows all classes published from any previous run. Use this to build a multi-class detector without re-segmenting classes you already have.
4
Segment

Click ▶ Run on the Segment card. GroundingDINO detects objects in each frame using the class name as a text prompt; SAM3 generates a precise mask; the best mask is cropped to a tight transparent PNG.

Classes already present are skipped automatically you can re-run segmentation safely. Progress streams live in the log panel.

5
Review segmented images

Click Open Review UI to open /review in a new tab. Use the class buttons at the top to switch between classes.

ActionWhat it does
Click imageToggle selection
Select all / ClearBulk selection
Delete selectedRemove bad crops permanently
Accept class →Keep all images, jump to next class
Reject classDelete all images in this class, jump to next
✓ Mark reviewedPublish all classes to the Global Repository, delete local copies, unlock Generate
Mark reviewed publishes each class automatically with the identifier {ClassName}_{run_name}. Generate is unlocked on the dashboard once this step completes.
6
Generate dataset

Click ▶ Run on the Generate card. The stage composites segmented objects onto random backgrounds to produce a synthetic YOLO dataset.

Output is split 80/10/10 into dataset/{train,valid,test}/ with a data.yaml. Set the Images field to control the total dataset size (default 15 000). Progress is logged every 100 images.

Tip: Ajust the dataset size based on the number of classes.
7
Train

Click ▶ Run on the Train card. Trains yolo11m on the generated dataset. Loss and mAP stream live in the log panel.

Configure Device (GPU index, e.g. 0), Epochs, and Batch size before starting.

8
Inference

Once training finishes, click Test model in the Train card (or go to /infer). Upload any image to run a prediction with the trained model. Results are drawn with bounding boxes and confidence scores.
